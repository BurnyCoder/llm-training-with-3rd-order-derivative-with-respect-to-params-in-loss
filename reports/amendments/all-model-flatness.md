# Comparable flatness measurements for every study arm

The initial checkpoint-flatness protocol covered selected fitted primary checkpoints. This extension adds every pilot strength, all trained controls, every hybrid branch and trunk, the initial predictors and the empirical unigram references. It was specified after early hybrid outcomes and the first TinyStories pilot geometry measurement. Preserve the original analyses and label the excluded Pythia numerical diagnostic separately. [Checkpoint-flatness protocol](checkpoint-flatness.md) · [Registered run matrix](../planned-runs.md)

**Weight-space geometry.** Apply the same eight-window, 16-direction level-set width and two-window, eight-probe float64 Hessian measurements within each trainable parameterization. For a hybrid reuse its existing final width after checking the exact weight digest. Reconstruct the zero-update neural predictor from the registered seed and pinned architecture. Use a stored initialization digest when available and verify the early TinyStories initialization against its logged first ordinary training batch. The unigram predictor is a fixed, add-one-smoothed table of training-token frequencies. It has zero trainable Transformer or adapter coordinates. [Width procedure](../../src/thirdloss/width.py) · [Unigram estimator](../../src/thirdloss/evaluation.py)

**Common output-score geometry.** On the same eight training windows, add a shared vocabulary bias to the logits for every position. Give each token a sign of +1 or −1, with equal counts for the two study vocabularies. Use 16 predetermined balanced sign vectors generated on the CPU with seed 88731, stream 991 and indices 0 through 15. Each model in a stage receives the same token-level perturbations. At radius r the root-mean-square change per vocabulary logit is r. Use the same outward grid, bisection and 0.1-nat rise to measure two-sided width. For the unigram predictor take the logarithms of its smoothed probabilities as its logits.

For a given direction, let a be the unperturbed probability mass on tokens with positive sign, and let s be the sign of the observed next token. At each position the exact NLL change is log(a exp(r) + (1 − a) exp(−r)) − r s. Average these changes across target positions. Its second derivative at zero is 4a(1 − a). Save all directional curvatures and crossing brackets, the median two-sided width, the distribution of directional widths, the checkpoint or reference fingerprint and the training-window fingerprint. The formula follows by factoring the softmax partition function. [Log-softmax definition](https://docs.pytorch.org/docs/stable/generated/torch.nn.LogSoftmax.html)

Larger output-score width means greater tolerance to shared changes in token scores. This complements weight-space flatness. Lower held-out NLL remains the prediction criterion. Show comparisons within a corpus at the same token horizon, identify each seed cohort and keep the diagnostic precision run separate. No decision about training strength or significance uses these supplementary outcomes.
