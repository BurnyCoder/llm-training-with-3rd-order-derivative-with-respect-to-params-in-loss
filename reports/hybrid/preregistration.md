## Question and design

Does responding to low curvature preserve more directional width than a fixed late ramp or another seed’s replayed coefficients? Does it improve prediction on the held-out development documents? The suggested mechanism is a measurable change in the width of a low-loss neighborhood in the fixed training coordinates. A coefficient can stay zero, widths can shrink, and better width can coexist with higher prediction loss. A late switch to a different objective has been studied with sharpness-aware minimization in image classification. [Zhou et al., Figure 1](https://proceedings.iclr.cc/paper_files/paper/2025/file/35d5ad984cc0ddd84c6f1c177a2066e5-Paper-Conference.pdf#page=2) · [Parameterization dependence](https://proceedings.mlr.press/v70/dinh17b.html)

Use the prepared TinyStories corpus, all trainable weights, architecture, AdamW, two-window derivative batch, 1/8 gate with eightfold active scaling, data order and 16,777,216-target horizon of the original full-weight experiment. Reserve seeds 21–28 for eight paired trajectories. Each effective update processes 32 windows of 128 targets. Use the original independently selected 1% initialization-calibrated coefficients as the constant base trace coefficient α and the third-order cap λmax. This makes the follow-up conditional on the published development selection. The official TinyStories test split is reserved for the original experiment. ## Run matrix

Each seed trains a common trace-only trunk for the first 8,388,608 targets (step 2048) with the full-horizon learning-rate schedule. Save the exact model, optimizer moments, RNGs, data cursor and last monitor measurements. Five arms resume that state. A sixth trains from the same raw initialization. All arms use the same monitoring budget. Distinct random streams generate the monitoring probe, trace probe and third-order probe pair. Within an update the penalty terms use the same two training windows.

| Arm | Coefficients applied to the two-window trace and squared third derivative |
|---|---|
| Trace alone | Continue with α only. |
| Stronger trace | Use α + s(t)Δα. At the shared checkpoint set Δα = λmax times the median ratio of third-penalty gradient norm to trace-penalty gradient norm over 16 separately addressed training batches. Match the median before clipping and publish all calibration draws. |
| Fixed late hybrid | Keep α and add s(t)λmax. The ramp s(t) increases linearly from zero at step 2048 to one at step 3072 and then stays there. Use the target count before the update. |
| Adaptive hybrid | Keep α and use the capped, nondecreasing past-curvature rule below. |
| Cross-seed replay | Keep α and replay the adaptive coefficient history one seed back around the cycle 21–28. Thus seed 21 receives seed 28’s history and seed 22 receives seed 21’s. Preserve actual coefficients and their timing, including zero histories. Keep the receiver's gates and data. |
| Always-on hybrid | Use α and λmax from step zero. Measure its own width at the common switch time. |

## Curvature rule

Every 16 completed updates measure q = ‖Hz‖²/d at the pre-update weights on two training windows with an independent, unnormalized random sign vector z. Record the ordinary training NLL of the effective batch at this measurement. Here d counts all trainable weights. Keep the last eight measurements. For the next update, c = √mean(q) and the loss criterion is mean NLL ≤ 4.0 nats. The original seed-zero training logs informed the choice of a low-loss threshold. [Training-only pilot measurements](../../results/stories-pilot-s00-hessian_norm-r03/events.jsonl) · [Hessian norm identity](https://arxiv.org/pdf/2010.09649)

Fix c* separately for each seed at the rolling RMS at its shared branch point. Its value stays fixed for every branch of that seed. Start λ at zero. Once warm-up is complete, eight past measurements exist and the loss criterion is met, latch eligibility. On every subsequent update set λ to the greater of its previous value and λmax × max(0, 1 − c/c*). Hold the coefficient constant through differentiation. Publish the exact change points for replay, monitor values, ordinary loss, pre-clipping update-gradient norms, active penalties and realized time spent at zero.

## Endpoints and falsification

Measure width after steps 2048, 3072 and 4096. Use the same eight training windows (data stream seed 88731, first batch), and the same 16 Rademacher directions normalized to unit Euclidean norm across all trainable weights. Fix the directions across seeds, arms and checkpoints. For each sign along each ray, find the first sampled radius at which unregularized NLL exceeds its unperturbed value by 0.1 nats per target. Search outward over powers of two from 1/8 to 128, then bisect the first observed crossing bracket 12 times. Publish the brackets and every censored ray. This grid estimates the first crossing and can miss sub-grid excursions. Restore the exact weights after perturbation. [Width definition](../../docs/third-derivative-penalty.md#from-a-local-penalty-to-basin-width)

The width is the median across directions of the sum of the two crossing radii. Propagate right-censoring through the median bounds. An unidentified median remains censored. The geometric endpoint is the change in median width from the common trace checkpoint to the full budget. Compare adaptive minus fixed and adaptive minus replay by exact one-sided paired sign tests for larger width, omitting exact ties. Holm-correct these two comparisons within the follow-up at 0.05. Require eight finite paired differences for each comparison and both adjusted tests to pass. Report each seed, the paired median and a distribution-free median interval. Equal or narrower widths weaken the proposed geometric advantage. Trace alone, stronger trace and always-on provide descriptive comparisons. Equally wide stronger-trace models weaken the distinct-order explanation.

Report full development NLL at the equal-token horizon and the fixed training-probe NLL separately. In that predictive comparison a negative adaptive-minus-comparator difference favors the adaptive method. For the interpretation of comparable fit, flag each pair whose final training-probe NLL differs by more than 0.02 nats; keep every pair in the report. Width alone provides geometric evidence. The development corpus has participated in the earlier pilot, which limits the predictive inference. Report optimizer time including monitoring, physical memory, calibration and width-probe cost, and the compute saved by sharing trunks. Keep the original stage-level test decisions and the hybrid width family separate.
