# Hybrid follow-up methods review

The adaptive rule sees lagged training measurements. Its scale is fixed once, from the last eight curvature measurements before branching. The user-requested late schedule retains a signed Hessian trace alongside the sampled squared third derivative. All arms draw the same gate sequence. Independent sign streams serve the trace, the third derivative and the curvature monitor. Zero realized coefficients remain eligible observations. [Preregistration](../hybrid/preregistration.md) · [Implementation](../../src/thirdloss/hybrid.py)

The checkpoint carries AdamW moments, the full-horizon rate schedule, next window address, RNGs, curvature history and coefficient history. The tests restore a parent into a separate optimizer and compare the next update coordinate by coordinate. An exact quadratic checks both directional crossing distances. A constant loss checks right-censoring. A parameter hash before and after the probe checks model restoration on every measured checkpoint. [Acceptance suite](../../tests/test_hybrid.py) · [Verification record](../../results/verification/tests.json)

The search estimates the earliest crossing seen on a finite radial grid in a fixed embedding and parameterization. It can miss a narrower excursion. The width sample uses fixed training windows and directions, so its intervals support inference over seeds conditional on these choices. Quantities averaged over unseen training batches or alternative weight scalings can differ. The exact sign test also assumes independent signs across pairs. The replay control shares each donor schedule with another seed, which can induce dependence. The registered report includes all paired differences, fit flags and censoring so this assumption can be inspected. [Definition and controls](../hybrid/preregistration.md) · [Coordinate dependence](https://proceedings.mlr.press/v70/dinh17b.html)

The development set already informed the original 1% coefficient selection. The two primary sealed-test hypotheses stay unchanged. Better directional width without better full-development prediction would support a geometric effect in these coordinates while leaving any predictive benefit unresolved.
